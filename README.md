# 🔐 Authentication System

This project is an authentication system for a web application that supports secure user registration and login. It utilizes **JSON Web Tokens (JWT)** for authentication, ensuring that only authorized users can access protected resources and perform sensitive actions.

## 🚀 Features

- ✅ User Registration
- ✅ User Login
- ✅ JWT-based Authentication
- ✅ Protected Routes
- ✅ Secure Session Handling with Token Expiration
- ✅ Scalable and Secure Architecture

## 🛠️ Tech Stack

- Backend: Node.js, Express 
- Authentication: JWT
- Database: MongoDB

## 📦 Installation

1. **Clone the repository:**

```bash
 git clone https://github.com/mahendra-singh-jhala/e-commerce-backend
```

2. **Install dependencies**

```bash
 npm install
```

3. **Run the backend server**

```bash
 npm run dev
```
